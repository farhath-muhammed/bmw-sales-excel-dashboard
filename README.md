# BMW Sales Dashboard | Excel

A one-page Excel KPI dashboard built with pivot tables, summarizing 15 years of BMW sales data across 6 regions and 11 models.

## Objective

Condense a large sales dataset into a single page that can be reviewed quickly.

## Dashboard KPIs

- Total Sales
- Total Revenue
- Average Mileage
- Average Price

## What's Inside

- Analysis of **15 years** of sales data
- Coverage of **6 regions** and **11 models**
- Pivot tables for sales volume, revenue, average mileage, and average price
- A clean one-page dashboard layout

## Tools Used

- Microsoft Excel (Pivot Tables, Dashboard design)

## Dataset

BMW sales dataset. Source: ADD_SOURCE (for example, Kaggle link).

## How to Use

1. Download the `.xlsx` file from this repo.
2. Open it in Excel and go to the **Dashboard** sheet.
3. The pivot table sheets show the underlying analysis.
